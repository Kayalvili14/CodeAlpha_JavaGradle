\# Java Expense Calculator



CodeAlpha DevOps Internship — Task 3

Created by Kayalvili Balendran



\## About

A Java application that calculates total expenses and remaining money.

Gradle builds the application and runs three JUnit tests.

GitHub Actions automatically builds, tests, and saves the ZIP package.



\## Requirements

JDK 21 and internet access for the first build.



\## Run

```powershell

.\\gradlew.bat run

```



\## Test

```powershell

.\\gradlew.bat test

```



\## Build

```powershell

.\\gradlew.bat clean build

```



Application packages are created in build/distributions.
